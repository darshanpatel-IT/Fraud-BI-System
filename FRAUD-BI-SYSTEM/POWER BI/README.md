# 📊 Power BI Dashboards

This folder contains the Power BI reporting and visualization work for the **Fraud BI System** project.

The dashboards transform SQL analysis into interactive business intelligence reports for monitoring fraud, transactions, merchants, and customer behavior.

## 📈 Dashboard Modules

### 1. Fraud BI Executive Dashboard
Provides a high-level overview of the most important business and fraud KPIs.

**Focus Areas:**
- Total transactions
- Transaction amount
- Fraud transactions
- Fraud rate
- Failed transactions
- Transaction trends
- Overall business performance

### 2. Fraud Analysis Dashboard
Focuses specifically on fraud patterns and transaction risk.

**Focus Areas:**
- Fraud transaction analysis
- Fraud rate
- Payment-method fraud patterns
- Transaction status analysis
- High-risk activity

### 3. Merchant Performance Dashboard
Analyzes merchant-level transaction and business performance.

**Focus Areas:**
- Merchant transaction volume
- Merchant revenue
- Fraud activity by merchant
- Failed transactions
- Merchant performance comparison

### 4. Customer Insights Dashboard
Analyzes customer transaction behavior and spending patterns.

**Focus Areas:**
- Customer spending
- Transaction frequency
- Customer activity
- Payment behavior
- Customer-level insights

## 🛠️ Power BI Skills Demonstrated

- Data Modeling
- DAX
- KPI Development
- Interactive Dashboards
- Slicers and Filters
- Data Visualization
- Business Intelligence
- Fraud Analytics

## 🎯 Purpose

The Power BI dashboards provide decision-makers with an interactive view of transaction performance and fraud risk.

**MySQL → SQL Analysis → Power BI → DAX → Interactive Dashboards → Business Insights**
