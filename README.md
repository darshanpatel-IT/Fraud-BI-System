# Fraud BI System

An end-to-end fraud analytics and business intelligence solution built using MySQL, Python, Power BI, and DAX.

## Project Overview

This project simulates a digital payment ecosystem and analyzes transactions to identify fraud patterns, merchant performance, and customer behavior.

## Dataset Scale

- 5,000 Customers
- 500 Merchants
- 50,000 Transactions
- 1,500 Fraud Cases

## Tech Stack

- MySQL
- Python
- Power BI
- DAX

## Dashboard Pages

### 1. Fraud BI Executive Dashboard
- Transaction KPIs
- Fraud KPIs
- Payment Method Analysis
- Merchant Performance Overview

### 2. Fraud Analysis Dashboard
- Fraud Detection Metrics
- Fraud by Device Type
- Fraud by Payment Method
- Fraud by Risk Level
- Fraud by City

### 3. Merchant Performance Dashboard
- Revenue Analysis
- Merchant Success Rate
- Merchant Failure Rate
- Merchant Fraud Analysis

### 4. Customer Insights Dashboard
- Customer Spending Analysis
- Payment Preferences
- Customer Segmentation
- Device Usage Analysis
